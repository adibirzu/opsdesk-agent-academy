    Know the boundary

    • Tools are synthetic

      The agent reads simulated service status, logs and traces. It does not inspect your own systems.

    • Remediation stops for approval

      Try a blocked action to see the policy stop the request before the model runs. Nothing is restarted.

    • Check the monitoring tools

      Sent does not mean visible yet. Find the trace ID in APM and Langfuse, and its events in Log Analytics.
