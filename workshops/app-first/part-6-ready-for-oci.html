THE FIVE-MINUTE WALKTHROUGH · KEEP THE APP YOU BUILT

Move the agent, not your whole workshop.

Your browser still shows OpsDesk. Its application server forwards an approved request to the hosted agent. The server protects the credentials. The agent keeps its tool rules and sends configured telemetry to each destination.

OpsDesk browser→Private app server→OCI hosted agent

Separate evidence path: agent → OpenTelemetry → Langfuse and, when separately configured, OCI APM. Structured application/security logs need their own Log Analytics integration. One connected destination does not prove the others.

  1. Minute 1 · point to the runtime. An OCI Application holds runtime settings. Its active Deployment selects a reviewed container image. Show which version would serve the request.
  2. Minute 2 · point to the boundary. Find the server-side bridge. Explain how its supported authentication reaches OCI. Keep cloud credentials out of browser code.
  3. Minute 3 · point to the contract. Compare the app's request/response with the container endpoint. The Lovable TypeScript app is not automatically the Python coordinator image; a real adapter is required.
  4. Minute 4 · point to the proof. On a separately approved target, invoke one synthetic task. Match its result and exact telemetry in each configured system. Otherwise show the unexecuted runbook and say deployment is pending.
  5. Minute 5 · point to the owner. Name who can approve changes, monitor cost, roll back and stop the exact resources. Keep live identifiers in a private operator record.

OCI Applications and Deployments → explains runtime configuration and image selection. Using an application → explains finding the endpoint and its authentication mode.
