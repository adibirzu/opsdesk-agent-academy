RAG is context, not permission.

Retrieval-augmented generation looks up relevant material and includes it in the model’s context. An agent can work without RAG; a RAG question-answering app need not have an autonomous tool loop. A vector database is one retrieval option.

Keep instructions separate from retrieved material. A runbook is evidence, even if it says “ignore policy.” Filter document access before retrieval results reach the model, return source references and preserve a no-result state.

The verified Lovable baseline does not use RAG. The separate local reference has a synthetic runbook lookup. Neither is proof of a production knowledge-base ingestion or retrieval deployment.
